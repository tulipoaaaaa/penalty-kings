## First steps in the new session

1. `date -u`; hard deadline for the submission text: **Sep 29 18:00 UTC**.
2. Check the network:
   `curl -s -X POST https://rpc.mainnet.chain.robinhood.com -H 'content-type: application/json' -d '{"jsonrpc":"2.0","id":1,"method":"eth_chainId","params":[]}'`
   must return `0x1237`.
3. `npm ci && npm run local:playwright` (the container ships Chromium for Playwright 1.56). Then
   install Foundry if it is missing: download
   `https://github.com/foundry-rs/foundry/releases/download/stable/foundry_stable_linux_amd64.tar.gz`
   into `~/.foundry/bin`.
4. The burner is `BURNER_MNEMONIC` (the owner's fresh wallet). `scripts/lib/wallet.mjs` reads it.
   **Never print it.** Import it into the keystore `pk-burner` for forge
   (`cast wallet import pk-burner --mnemonic "$BURNER_MNEMONIC"`, password in `~/.burner-pass`,
   chmod 600).
   - The address generated by the old session (`0x4475…83cd`) was never funded and is abandoned.
     Update `docs/ADDRESSES.md` / `DEPLOYMENT.md` with the new address.
5. Record funding with `setFunding` in `scripts/lib/budget.mjs` once the owner has sent ETH and
   named the launch size (see STOP 1 in the chat; budgets are in `scripts/onchain/budget-plan.mjs`).
